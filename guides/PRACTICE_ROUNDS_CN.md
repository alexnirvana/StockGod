# 多轮自由模拟

[English](PRACTICE_ROUNDS.md) · [简体中文](PRACTICE_ROUNDS_CN.md) · [返回首页](../README_CN.md)

Stock God 0.6 支持重复进行自由模拟，每一轮都有独立账户和保留的记录。练习使用现有固定教学数据，不是真实历史行情。

## 开始下一轮

1. 进入「自由模拟 → 新一轮练习」。
2. 在弹窗中核对轮次、教学日和虚拟资产。
3. 如有待处理订单，先撤单或推进教学日完成处理。新建轮次不会暗中取消订单。
4. 点击「归档并开始新一轮」。新账户从第 20 教学日开始，拥有 100,000 元虚拟资金、空持仓和独立初始流水。

旧账户变为只读，资金、持仓、订单、流水和复盘全部保留。归档不会自动卖出股票，持仓市值按旧轮次最后教学日的收盘价计算。到达第 60 日后仍可开始新一轮。

新轮次重复同一教学场景，适合练习不同决策，不能视为未见过的新数据。教学账户、课程进度、经验、听课记录和策略实验保持独立。

## 回看练习

进入「自由模拟 → 练习轮次 → 查看轮次记录」。弹窗展示资金与持仓市值、订单、持仓、资金流水、SG001 的可见行情和保存的复盘。较早轮次通过分页加载，行情不会超过该轮当前或归档时的教学日。

「保存本轮复盘」把计划和复盘关联到当前自由模拟账户。表单记录的是你对练习的文字回顾，不证明计划实际写于交易之前。归档后不能通过该入口追加或修改旧轮次的复盘。

## 保存与并发保护

- 账户按玩家、模式和轮次编号唯一。应用写操作在事务内锁定当前玩家，保证只创建一个当前轮次。
- 旧账户归档、新账户创建及初始资金流水在同一个事务提交。
- 自由模拟下单、推进日期和保存复盘携带 `expected_account_id` 与 `expected_day`。旧标签页操作收到 HTTP 409，不能把旧操作应用到新账户或新教学日。刷新页面后需重新核对操作。
- 相同幂等键与请求内容返回原结果；并发创建下一轮不会生成两个替代账户。
- 查看和导出仅限当前用户。其他用户的轮次返回 HTTP 404。
- 每个账户固定数据和规则版本。版本不可用时，明细估值返回 HTTP 503，轮次列表和原始数据导出仍可使用。

## 从 0.5 升级

先备份 MySQL，再重新构建服务。迁移 `f24ca6e36155` 保留原账户 ID 和余额，把已有账户设为第 1 轮，增加归档时间与数据版本。旧账户没有可靠的创建时间，因此保持为空。

`/api/export` 审计导出包含该用户全部轮次及关联记录。恢复数据库请使用完整备份，步骤见[运维说明](OPERATIONS_CN.md)。迁移不会执行丢弃后续轮次的破坏性降级。

## 接口与验证

| 接口 | 用途 |
| --- | --- |
| `GET /api/accounts/free` | 当前自由模拟账户 |
| `GET /api/practice/rounds?limit=20&before=3` | 按轮次倒序分页 |
| `GET /api/practice/rounds/{account_id}` | 包含复盘的只读账户详情 |
| `POST /api/practice/rounds` | 归档当前轮次并开始下一轮 |

最后一个接口只接收 `expected_account_id` 和 `expected_day`，初始资金、时钟和轮次由后端决定。写操作继续要求 Cookie、CSRF、来源校验和幂等键。0.6 之前已打开的自由模拟页面需要刷新以发送新的上下文字段。

回归覆盖记录保留、数据迁移、用户隔离、分页、幂等、并发归档与下单、并发推进、旧页面、防止数据末尾卡住，以及课程奖励不受影响。界面复用紧凑工作区和已有弹窗。
